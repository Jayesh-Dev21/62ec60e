# SHA1-Hulud Attack 

Also known as the shai-hulud worm attack, was pretty got pretty famous recently.

This lab recreates a controlled simulation inspired by the recently publicized "Shai-Hulud Worm" attack to study worm propagation, persistence techniques, and detection strategies. It is intended solely for defensive security research, malware analysis, and incident response training within isolated environments. Do not deploy outside authorized laboratory systems.
